Add `hypequery schema inspect`, `hypequery onboard analyze` and `hypequery onboard check`: hypequery Cloud's onboarding analysis against your own ClickHouse. `schema inspect` reports tables, columns and engine metadata; `onboard analyze` adds first-pass findings and the questions to ask, grain checks, measured join candidates, column role hints, access-profile risks, grants, query-history observations and possible tenant columns (reported, never applied); `onboard check` verifies a datasets file's measures and joins against the data and exits 1 with `ONBOARD_CHECK_FAILED` while anything fails. All three support `--json`. The analysis comes from `@hypequery/onboard-engine` (`^0.1.0`), which the CLI loads at runtime from the project (or beside the CLI with `npx -p`) rather than depending on it; without it the CLI offers to install it at a terminal, and fails with `ONBOARD_ENGINE_MISSING` under `--json`, `--no-input` or CI. Query history without its grant is a warning, not a failure. A relationship whose table or column doesn't exist, or whose keys have different types, fails `onboard check`; one that can't be measured is a warning. Join split values follow `--samples` like other sampled values. A settings profile ClickHouse reports unexpectedly fails with `CLICKHOUSE_PROFILE_UNREADABLE` instead of a retryable connection error, and an engine that is newer than the CLI supports asks for a newer CLI. A join candidate's `reason` no longer carries split values the sample policy withholds, and a partition ID (`recentPartitionId`, a check's `scope.partitionId`) is withheld under `--samples none` or when the partition key reads a withheld column. Text from ClickHouse and the engine is printed without terminal control characters (`--json` is unchanged). The ClickHouse transport doesn't follow redirects (they fail with `CONNECTION_FAILED`), and plain `http://` to a host other than localhost prints a one-time warning that credentials travel unencrypted. The project's engine is read only from the project root's `node_modules`, never from a parent directory's.
