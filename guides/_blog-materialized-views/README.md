# SQL behind "A guide to materialized views in ClickHouse"

The blog post at `/blog/a-guide-to-materialized-views-in-clickhouse` says its
statements run on the seed dataset. These files are those statements, adapted
to the seed's `events` table, and CI runs them against ClickHouse 25.8 on every
change. When you edit a SQL block in the post, edit it here too.
