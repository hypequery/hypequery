- Retry server-side `KILL QUERY` from the async executors until ClickHouse confirms it or the driver call returns. A cancellation or deadline that landed before the query registered on the server previously let the query run to `max_execution_time` while holding its worker slot; the synchronous executor already retried. `AsyncFromSyncClickHouseExecutor` keeps retrying for as long as its driver call runs, so a submission slower than `max_execution_time` cannot escape cancellation; the native async executor, which cannot see its driver call, stops at the server's own time limit.
