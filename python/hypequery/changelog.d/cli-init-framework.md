- `hypequery init --framework django|flask` scaffolds for Django and Flask instead of FastAPI. Django gets an `analytics.py` (registry, tenant function and an example view) for an existing project, and the README shows the `settings.py` and `urls.py` lines. Flask gets an `app.py` using the `Hypequery` extension. The tenant function returns `None` until it is wired to a login, so tenant-keyed datasets refuse to run. `pyproject.toml` asks for the `django` or `flask` extra. FastAPI stays the default.
