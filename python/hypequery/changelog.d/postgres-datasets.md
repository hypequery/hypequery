- Run datasets on Postgres. `create_postgres_executor` and `create_async_postgres_executor` (extra `hypequery[postgres]`) execute queries the client compiles with the new Postgres dialect; results match ClickHouse for the same rows, including DST buckets, half-to-even `round` and NULL ordering. Queries run read-only with a server-side statement timeout and cancellation, and time-key filters keep an index on the column usable.
- `TypedParameter.clickhouse_type` is now `sql_type`, `CompiledQuery` records the `dialect` it was compiled for, and executors refuse queries compiled for another dialect. `SafeIdentifier` no longer renders SQL itself; quote names through the dialect.
