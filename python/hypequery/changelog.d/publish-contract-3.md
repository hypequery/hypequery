- `build_protocol_deployment_contract`, `prepare_dataset_bundle` and `write_dataset_bundle` publish segments, window and shift measures, and `approxCountDistinct` measures as deployment contract 3 (RFC 0015), byte for byte what TypeScript emits for the same definition. A deployment that uses none of them is still contract 2, with the same bytes and identity as before. Contract 3 marks estimating measures `approximate` (including windows, shifts and derived measures over them), and a contract 3 bundle is identified in the `hypequery:deployment:v3` domain.
- A published dataset now accepts every grain, `minute` through `year`, and no contract carries a dataset-level grain restriction. Publishing therefore refuses `time_grains` unless it lists all seven grains; remove it to publish.
- `build_protocol_dataset_contract` (the standalone contract 2 snapshot) refuses window and shift measures, segments and `approxCountDistinct` by name instead of dropping them or failing with a contract path.
- `hypequery.protocol` adds `prepare_protocol_deployment_contract_any_version` and `validate_protocol_deployment_contract_any_version`, which select contract 2 or 3 by the envelope's `version`.
