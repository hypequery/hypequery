- `hypequery.protocol` validates RFC 0029 query fields: the `inDateRange` comparison (query filters only, with values such as `"last 30 days"`, `"this quarter"` or `"year to date"`; `parse_protocol_relative_date_range` and `is_protocol_relative_date_range` read the grammar) and the dataset query's `fill` flag (`ProtocolDatasetQuery.fill`, which requires `by`). Cache preimages refuse a relative range or `fill: true`, and `fill: false` keys like an absent flag. Python execution of relative ranges and filled series comes later; until then they are refused, never dropped.
