- `hypequery.protocol` accepts RFC 0029 time-key selection: a semantic query's `timeKey` (`ProtocolDatasetQuery.time_key` / `ProtocolMetricQuery.time_key`) and a contract 3 dataset's `alternateTimeFields` (non-empty, distinct, never `timeField`, only beside one; a dataset carrying them is contract 3). Cache preimages refuse a query that names a `timeKey`. Python datasets do not declare alternate time keys yet.
