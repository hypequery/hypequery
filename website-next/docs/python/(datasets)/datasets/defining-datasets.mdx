A dataset is a semantic model over a source table or view.

<CodeBlock>
```python
from hypequery.datasets import Dataset, dimension, measure

orders = Dataset(
    name="orders",
    source="orders",
    tenant_key="tenant_id",
    time_key="created_at",
    dimensions={
        "id": dimension("number"),
        "created_at": dimension("timestamp"),
    },
    measures={
        "revenue": measure.sum("amount"),
    },
)
```
</CodeBlock>

`name` is the logical dataset name and `source` is the physical table or view. `tenant_key` and `time_key` are the
columns used for runtime tenant isolation and time grains.

Datasets are immutable Pydantic models, validated when you create them. Define them at module level and import them
where you query. The `dataset(name, *, source=..., dimensions=..., ...)` helper builds the same model with the
keyword spelling the TypeScript `dataset()` entrypoint uses.

## Fields

A dataset can include:

- `name` and `source`
- `tenant_key`
- `time_key`
- `dimensions`
- `measures`
- `filters`
- `relationships`
- `limits`

See [Dimensions](/docs/python/datasets/dimensions), [Measures](/docs/python/datasets/measures), and
[Relationships](/docs/python/datasets/relationships) for the main building blocks.
