---
title: Feature status
description: What the Python SDK supports today compared with TypeScript.
---

The Python SDK is in beta. This table tracks coverage against the TypeScript packages.

| Feature | TypeScript | Python |
| --- | --- | --- |
| Dimensions and base measures | Available | Available |
| Filtered measures | Available | Available |
| Relationships (`belongs_to`, `has_one`, `has_many`) | Available | Available |
| Time grains | Available | Available, including per-dataset `time_grains` restriction |
| Sync and async execution | Available | Available |
| Result caching and multi-tenancy | Available | Available |
| Dataset catalog | Available | Available |
| `approxCountDistinct` measures | Available | Planned |
| `measure.merge` over `AggregatingMergeTree` state columns | Available | Planned |
| `final: true` for `ReplacingMergeTree` / `CollapsingMergeTree` sources | Available | Planned |
| Derived measures | Available | Available (`measure.derived` with `formula.*`) |
| Window measures (trailing, to-date, cumulative) | Available | Planned |
| Period comparisons (`shift`) | Available | Planned |
| Segments | Available | Planned |
| Relationship checks | Available | Available (`check_relationships`) |
| Cloud publishing | Available | Bundle export available (`write_dataset_bundle`); one-step publish planned |
| MCP server for AI agents | Available | Through the Node `hypequery mcp` bridge over the server's live client contract ([setup](/docs/python/client-endpoints)); no native Python server |
| Tool generation for agents | Available | Under consideration |
| Serve: auth, CORS, rate limiting, errors | Available | Available |
| Serve: dataset query endpoints and discovery | Available | Available |
| CLI (`init`, `generate datasets`, `dev`, `export client-contract`) | Available | Available |
| Generated React hooks | Available | Available via exported client contracts and `generate:client` ([setup](/docs/python/client-endpoints)) |
| Query builder | Available | Not planned |
| Named metrics | Available | Not planned. Use metric endpoints or derived measures |
