The Python SDK lets you define a semantic layer over ClickHouse (datasets with dimensions, measures, and
relationships) and query it from Python, with tenant isolation and result caching built in, then serve it over HTTP
with an authenticated-by-default API that runs under any ASGI or WSGI server, mounts in FastAPI or Starlette, and is
served natively from Django and Flask.

The same served endpoints can feed generated, type-safe React hooks (`@hypequery/react`) and AI agents through the
`hypequery mcp` bridge, so the frontend and agents use the definitions Python owns. See
[React and MCP clients](/docs/python/client-endpoints).

Python and TypeScript implement the same specifications and run against the same conformance fixtures, so equivalent
definitions produce identical semantic and deployment artifacts. The APIs are idiomatic to each language rather than
line-for-line ports. The Python SDK does not include the TypeScript query builder.

## Install

Install the SDK with optional extras for each executor and for serving:

<CodeBlock>
```bash
pip install hypequery
pip install "hypequery[clickhouse]"        # sync ClickHouse executor
pip install "hypequery[clickhouse-async]"  # async ClickHouse executor
pip install "hypequery[server]"            # uvicorn, for hypequery dev and start_server
pip install "hypequery[jwt]"               # JWT authentication
pip install "hypequery[django]"            # Django integration (or [flask])
pip install "hypequery[pandas]"            # typed DataFrames (or [polars], [arrow])
```
</CodeBlock>

Python 3.11 or later is required.

## Packages

| Module | Purpose |
| --- | --- |
| `hypequery.datasets` | Dimensions, measures, relationships, the dataset client, caching, and the catalog |
| `hypequery.execution` | Sync and async ClickHouse executors |
| `hypequery.serve` | An authenticated-by-default HTTP API with ASGI and WSGI adapters, JWT auth, CORS and rate limiting |
| `hypequery.contrib` | [Django](/docs/python/django), [Flask](/docs/python/flask) and [SQLAlchemy](/docs/python/sqlalchemy) integrations, including native Django and Flask serving |
| `hypequery` CLI | `hypequery init`, `generate datasets`, `dev` and `export client-contract`; see [Python CLI](/docs/python/cli) |
| `hypequery.protocol` | The language-neutral artifact contracts shared with TypeScript |
