`create_app(router, security=...)` installs the HTTP security profile. To add it to an existing FastAPI app instead,
call `install_http_security(app, security)`.

<CodeBlock>
```python
from hypequery.serve import CorsPolicy, HttpSecurity, create_app

app = create_app(
    router,
    security=HttpSecurity(
        allowed_hosts=("api.example.com",),
        cors=CorsPolicy(origins=("https://app.example.com",), allow_credentials=True),
        trusted_proxies=("10.0.0.0/8",),
    ),
)
```
</CodeBlock>

## Allowed hosts

`allowed_hosts` is required and must name hosts; `*` is refused. A request for any other `Host` gets `400` and is
never redirected.

## CORS

CORS is off unless `cors` is set.

- Origins must be exact `scheme://host[:port]` values.
- Credentialed CORS with a wildcard origin is refused when the policy is built, as are wildcard methods or headers.
- Defaults: methods `GET` and `POST`; headers `Authorization`, `Content-Type`, and `X-Request-ID`; `max_age` 600
  seconds.

## Trusted proxies

`X-Forwarded-For` and `X-Forwarded-Proto` are honored only from `trusted_proxies`. The client address is the nearest
forwarded address that isn't itself a trusted proxy. By default no proxy is trusted.

A trusted proxy must replace any caller-supplied `X-Forwarded-Proto` with the scheme it observed; forwarding the
caller's value lets the caller spoof it.

## Request ids

- Every response carries a server-generated `x-request-id`. Read it in a handler with `request_id(request)`.
- A caller's `X-Request-ID` is never authoritative. If it is short printable ASCII, it is echoed back as
  `x-correlation-id`; otherwise it is dropped.
