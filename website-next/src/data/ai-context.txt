# hypequery — context for an AI coding assistant

hypequery is an open-source TypeScript semantic layer and type-safe query builder for ClickHouse. Teams define analytics once, then reuse the same contract in backend jobs, multi-tenant APIs, React hooks, and MCP tools for AI agents.

## Packages

- @hypequery/clickhouse — generated schema types and fluent ClickHouse queries
- @hypequery/datasets — dimensions, measures, metrics, relationships, and tenant rules
- @hypequery/serve — validated HTTP APIs, OpenAPI, and local docs
- @hypequery/react — typed TanStack Query hooks
- @hypequery/mcp — governed MCP tools for approved analytics
- @hypequery/cli — project setup, schema generation, development, and deployment

## Start with a typed ClickHouse query

```typescript
import { createQueryBuilder } from '@hypequery/clickhouse';
import type { IntrospectedSchema } from './analytics/schema.js';

const db = createQueryBuilder<IntrospectedSchema>({
  url: process.env.CLICKHOUSE_URL!,
  username: process.env.CLICKHOUSE_USERNAME!,
  password: process.env.CLICKHOUSE_PASSWORD ?? '',
  database: process.env.CLICKHOUSE_DATABASE!,
});

const revenueByRegion = await db
  .table('orders')
  .select(['region'])
  .where('status', 'eq', 'completed')
  .sum('amount', 'revenue')
  .groupBy('region')
  .orderBy('revenue', 'DESC')
  .execute();
```

Generate the schema first with `npx hypequery generate`. Prefer bound, typed filters over interpolated SQL. The builder supports ClickHouse-native features including PREWHERE, FINAL, LIMIT BY, array joins, CTEs, settings, streaming, percentiles, argMax/argMin, and window expressions via selectExpr().

## Share analytics meaning with a dataset

```typescript
import {
  createDatasetClient,
  dataset,
  dimension,
  measure,
} from '@hypequery/datasets';

const Orders = dataset('orders', {
  source: 'orders',
  tenantKey: 'tenant_id',
  timeKey: 'created_at',
  dimensions: {
    region: dimension.string(),
    status: dimension.string(),
    createdAt: dimension.timestamp({ column: 'created_at' }),
  },
  measures: {
    revenue: measure.sum('amount'),
    orderCount: measure.count('id'),
    p95OrderValue: measure.percentile('amount', 0.95),
  },
});

const revenue = Orders.metric('revenue', { measure: 'revenue' });
const analytics = createDatasetClient({ queryBuilder: db });

const result = await analytics.execute(
  revenue,
  { dimensions: ['region'], limit: 10 },
  { runtime: { tenant: { id: tenantId } } },
);
```

A dataset is the shared contract for APIs, React dashboards, and MCP agents. Tenant-scoped datasets fail closed when trusted runtime tenant context is absent.

## Working conventions

- Start with @hypequery/clickhouse for local queries.
- Add @hypequery/datasets when definitions need reuse or governance.
- Add @hypequery/serve, @hypequery/react, or @hypequery/mcp only for the delivery surfaces needed.
- Run `npx hypequery generate` after a ClickHouse schema change.
- Check https://hypequery.com/docs/capabilities for the current public surface.

Docs: https://hypequery.com/docs/quick-start
